# LEC08 Animation Viewer

## 구현 목표

- `SamuraiSheet.png` 스프라이트 시트 사용
- 화면 중앙에서 캐릭터 애니메이션 재생
- 캐릭터를 화면에서 충분히 크게 확대
- 4종 이상의 동작을 각각 1초 동안 재생
- 모든 동작을 순서대로 무한 반복

## 점진적 개발 순서

1. Pico2D 캔버스 생성
2. 스프라이트 시트 로드 및 첫 프레임 출력
3. 프레임 좌표와 확대 비율 정의
4. 동작별 프레임 데이터 추가
5. 1초 단위 동작 전환과 무한 반복 구현
6. 종료 이벤트 처리 및 데이터 검증

## 실행 방법

```powershell
cd LEC08
python animation_viewer.py
```

창의 닫기 버튼이나 `ESC` 키로 종료할 수 있다.

자동 검증은 다음 명령으로 실행한다.

```powershell
cd LEC08
python -m unittest -v
```

## 구현한 애니메이션

| 순서 | 동작 | 행 | 프레임 수 | 재생 시간 |
| ---: | --- | ---: | ---: | ---: |
| 1 | Idle | 0 | 6 | 1초 |
| 2 | Walk | 1 | 8 | 1초 |
| 3 | Run | 2 | 8 | 1초 |
| 4 | Dash | 3 | 12 | 1초 |

각 동작의 프레임 간격은 `1초 / 프레임 수`로 계산한다. 따라서
프레임 수가 서로 달라도 각 동작은 정확히 1초 동안 재생된다.

## 채점 기준 대응

- 정확한 애니메이션 재생: 각 행의 실제 프레임 수와 128×128 좌표 사용
- 확대: 640×480 화면에서 384×384 크기로 출력
- 무한 반복: 마지막 Dash 다음에 다시 Idle로 순환
- 복잡한 시트: 1536×1280 시트의 여러 행 사용
- 서로 다른 프레임 수: 6, 8, 8, 12 프레임 지원
