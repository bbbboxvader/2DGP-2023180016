# LEC08 Animation Viewer

## 구현 목표

- `SamuraiSheet.png` 스프라이트 시트 사용
- 화면 중앙에서 캐릭터 애니메이션 재생
- 캐릭터를 화면에서 충분히 크게 확대
- 4종 이상의 동작을 각각 1초 동안 재생
- 모든 동작을 순서대로 무한 반복

## 점진적 개발 순서

1. Pico2D 캔버스 생성
2. 스프라이트 시트 로드 및 첫 프레임 출력
3. 프레임 좌표와 확대 비율 정의
4. 동작별 프레임 데이터 추가
5. 1초 단위 동작 전환과 무한 반복 구현
6. 종료 이벤트 처리 및 데이터 검증
