# PRD: Sonic Animation Viewer

## 1. 프로젝트 개요

Pico2D를 사용하여 `sonic-sprite.png`에 포함된 Sonic의 동작을 순서대로 보여주는 애니메이션 뷰어를 제작한다.

- 실행 파일: `sonic_animation_viewer.py`
- 이미지 파일: `sonic-sprite.png`
- 실행 환경: 로컬 데스크톱, Pico2D
- 제출 형태: 단일 Python 소스 파일

## 2. 핵심 요구사항

1. Sonic의 연속 동작 애니메이션을 정해진 순서대로 재생한다.
2. 하나의 동작을 전체 프레임 기준으로 정확히 5회 반복한다.
3. 5회 반복이 끝나면 1초 동안 대기한 뒤 다음 동작으로 전환한다.
4. 마지막 동작이 끝나면 첫 번째 동작부터 다시 반복한다.
5. 캐릭터를 원본보다 크게 표시하되 가로세로 비율을 유지한다.
6. 창 닫기 또는 `ESC` 입력으로 프로그램을 종료한다.
7. 기능을 작은 단계로 나누어 개발하고 최소 20개의 의미 있는 커밋을 만든다.

## 3. AI 수정 및 보완 내용

- AI가 제목, 제작자 문구, 보조 캐릭터와 정지 이미지는 제외하고 Sonic의 연속 동작만 재생하도록 수정하였습니다.
- AI가 불규칙하게 배치된 스프라이트를 정확히 표시할 수 있도록 동작별 프레임 좌표와 크기를 직접 지정하도록 수정하였습니다.
- AI가 이미지 좌표와 Pico2D 좌표의 차이로 잘못된 부분이 출력되지 않도록 좌표 변환 방식을 추가하였습니다.
- AI가 각 애니메이션의 프레임 수와 재생 속도를 개별적으로 설정할 수 있도록 수정하였습니다.
- AI가 한 동작을 정확히 5회 재생한 후 1초 동안 대기하고 다음 동작으로 자동 전환하도록 수정하였습니다.
- AI가 마지막 애니메이션이 끝나면 첫 번째 애니메이션부터 다시 반복하도록 수정하였습니다.
- AI가 애니메이션 전환 대기 중에도 창 닫기와 `ESC` 입력이 정상적으로 처리되도록 수정하였습니다.
- AI가 캐릭터의 가로세로 비율을 유지하면서 화면 중앙에 충분히 크게 출력되도록 수정하였습니다.
- AI가 모든 프레임이 이미지 경계 안에 있는지 확인하여 빈 영역이나 다른 동작이 함께 표시되지 않도록 수정하였습니다.
- AI가 프로그램 종료 시 Pico2D 화면 자원이 정상적으로 정리되도록 수정하였습니다.
- AI가 제출 파일을 `sonic_animation_viewer.py` 하나로 유지하도록 수정하였습니다.
- AI가 기능을 단계별로 확인하며 최소 20개의 의미 있는 커밋으로 개발하도록 작업 순서를 정리하였습니다.

## 4. 상세 구현 사양

### 4.1 에셋 처리

- `sonic-sprite.png`는 스크립트 파일이 있는 폴더를 기준으로 불러온다.
- 스프라이트 시트의 크기는 399×525이다.
- 프레임이 일정한 격자로 배치되지 않았으므로 동작마다 `(x, y, width, height)` 값을 직접 정의한다.
- Pico2D의 아래쪽 기준 좌표계에 맞게 이미지 좌표를 변환한다.

### 4.2 애니메이션 데이터

각 동작에는 다음 정보를 기록한다.

| 항목 | 내용 |
| --- | --- |
| 이름 | 동작을 구분하는 이름 |
| 프레임 | `(x, y, width, height)` 목록 |
| 프레임 수 | 한 번 재생할 전체 프레임 개수 |
| 재생 속도 | FPS 또는 프레임 전환 간격 |
| 재생 순서 | 전체 동작 중 재생할 순번 |

### 4.3 재생 상태

프로그램은 다음 상태를 관리한다.

- 현재 동작 번호
- 현재 프레임 번호
- 현재 동작의 반복 횟수
- 프레임 전환 시간
- 동작 전환 전 1초 대기 시간
- 프로그램 실행 여부

긴 `delay()`로 프로그램을 멈추지 않고 시간과 상태를 확인하며 재생한다. 따라서 애니메이션 재생 및 대기 중에도 종료 이벤트를 처리할 수 있어야 한다.

### 4.4 화면 표시

- 프레임을 그리기 전에 화면을 지워 잔상이 남지 않게 한다.
- 캐릭터는 화면 중앙에 표시한다.
- 프레임마다 가로세로 비율을 유지한다.
- 가장 큰 프레임도 화면 밖으로 잘리지 않는 확대 배율을 사용한다.

### 4.5 종료 처리

- 창 닫기 이벤트를 처리한다.
- `ESC` 키 입력을 처리한다.
- 프로그램 종료 시 `close_canvas()`를 실행한다.
