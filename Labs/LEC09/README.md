# LEC09 Sonic Animation Viewer

## 실행

Pico2D가 설치된 Python 환경에서 다음 명령을 실행한다.

```powershell
cd Labs\LEC09
python sonic_animation_viewer.py
```

스프라이트 시트는 실행 위치와 관계없이 `sonic_animation_viewer.py` 옆의 `sonic-sprite.png`에서 불러온다. 창 닫기 또는 `ESC` 키로 종료할 수 있다.

## 테스트

워크스페이스 루트에서 실행한다.

```powershell
python -m unittest discover -s Labs\LEC09 -p test_sonic_animation_viewer.py -v
```

테스트는 프레임 좌표와 이미지 경계, 5회 반복, 동작 사이 1초 대기, 전체 순환, 최대 4배 확대, 이동·점프 경로, 종료 이벤트와 자원 정리를 확인한다. `test_sonic_animation_viewer.py`는 개발 검증용이며 제출 실행 소스에는 포함하지 않는다.

## 등록된 애니메이션

프레임은 스프라이트 시트의 비정형 배치에 맞춰 각 영역을 직접 지정한다. 타이틀, 크레딧, 보조 캐릭터와 정지 이미지는 재생 목록에서 제외한다.

| 순서 | 프레임 수 | 프레임 간격 | 화면 이동 |
| ---: | ---: | ---: | --- |
| 1 | 11 | 0.080초 | 좌 → 우 |
| 2 | 12 | 0.075초 | 좌 → 우 |
| 3 | 6 | 0.090초 | 좌 → 우, 점프 |
| 4 | 8 | 0.070초 | 제자리 |
| 5 | 12 | 0.065초 | 좌 → 우 |
| 6 | 6 | 0.085초 | 제자리 |
| 7 | 8 | 0.080초 | 제자리 |
| 8 | 8 | 0.075초 | 좌 → 우 |
| 9 | 4 | 0.110초 | 제자리 |

각 애니메이션은 전체 프레임을 5회 재생한 뒤 1초 대기하고 다음 순서로 전환한다. 이동 동작은 반복 진행률에 따라 화면 왼쪽에서 오른쪽으로 움직이고, 점프 동작은 상승·하강 궤적을 함께 표현한다. 캐릭터는 최대 4배로 확대하며 화면 밖으로 잘리지 않는다. 마지막 애니메이션 뒤에는 첫 애니메이션으로 돌아간다.
